# GitLab Skill Candidates

## Возможности

- Выбор репозитория по пользовательскому запросу и описаниям repositories.
- Code search по GitLab с коротким объяснением найденных файлов.
- Формирование ответа с ссылками на source evidence.

## Ограничения

- Не хардкодить file roles в Python; правила формата и описания должны жить в prompts.
- Не искать по backend, если пользователь явно ограничил вопрос mobile/frontend repo и router уверен в выборе.
