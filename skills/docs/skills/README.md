# Service Skill Candidates

Эта папка фиксирует capabilities сервисов, которые можно вынести или развить в skill layer.

- `api-gateway.md` - orchestration и routing capabilities.
- `auth.md` - auth/account support capabilities.
- `frontend.md` - UI/product instruction capabilities.
- `generator.md` - AI generation capabilities.
- `gitlab-skill.md` - GitLab code search capabilities.
- `shared.md` - protocol/schema capabilities.
