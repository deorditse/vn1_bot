# Auth Skill Candidates

## Возможности

- Объяснение auth-flow по login, refresh, logout, me и context.
- Диагностика cookie/JWT/Keycloak проблем по логам и конфигурации.

## Ограничения

- Не раскрывать токены, client secrets и персональные данные.
- Не выполнять destructive auth actions без отдельного подтверждения.
