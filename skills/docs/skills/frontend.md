# Frontend Skill Candidates

## Возможности

- Поиск пользовательского сценария в frontend-коде.
- Объяснение связки page, widget, feature, entity и API client.
- Подготовка инструкции для UI-изменения по существующей архитектуре.

## Ограничения

- Не генерировать отдельную дизайн-систему вместо существующего UI.
- Не делать вывод о backend-поведении без проверки API-контракта.
