# Generator Skill Candidates

## Возможности

- Подготовка и проверка AI generation prompts.
- Диагностика file/text input flow.
- Объяснение обработки документов и коротких AI-описаний.

## Ограничения

- Не логировать полный пользовательский текст, если он может содержать приватные данные.
- Не вызывать provider-specific функции без settings/env gate.
