# Генерация описаний из разметки

## Пользовательский сценарий

Авторизованный пользователь открывает отдельный раздел «Генерация из разметки», выбирает XLS/XLSX-файл с колонками `id` и `разметка сырая` либо вводит один `id` и сырой текст вручную. Источники взаимоисключающие. После генерации браузер скачивает XLSX с колонками эталонного `output.xlsx`.

## API-контракт

`POST /generator/generate-description`

- `multipart/form-data`: поле `file`, расширение `.xls` или `.xlsx`;
- либо `application/json`: `{ "id": string | number, "raw_description": string }`;
- ответ: XLSX attachment;
- ошибки валидации: HTTP 422.
- ограничения: файл до 10 МБ, до 100 строк и до 100 000 символов сырой разметки на строку.

## UI-состояния

Начальное, выбранный файл/заполненная форма, загрузка, ошибка и успешное скачивание. Во время запроса поля и переключатель источника заблокированы.
