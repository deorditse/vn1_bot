# Средства гигиены и расходные материалы

## Заголовок

Формат:

<Наименование> <количество/объём>

---

## Особенности вводного абзаца

Обязательно указать:

- тип изделия;
- количество;
- назначение как категорию использования;
- материал;
- основные характеристики;
- краткий способ применения.

Не использовать медицинские или профилактические заявления.

---

## Особенности формирования карточки

Для влажных салфеток указывать состав пропитки.

Для подгузников указывать:

- размеры;
- весовую категорию;
- количество слоёв;
- впитываемость;

если эти сведения присутствуют.

Для масок и перчаток указывать размер.

Если присутствуют:

- не содержит латекс;
- гипоаллергенно;

их можно вывести только при наличии в инструкции.

Не использовать профилактические обещания.
