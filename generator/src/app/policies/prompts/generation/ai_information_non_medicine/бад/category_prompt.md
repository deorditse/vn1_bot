# БАД

## Заголовок

Формат:

<Наименование> <количество> <форма выпуска>

Форма выпуска должна быть краткой:
- таблетки
- капсулы
- порошок
- саше
- пастилки

Без уточнений вроде «таблетки, покрытые оболочкой».

---

## Особенности вводного абзаца

Обязательно указать:

- что продукт является биологически активной добавкой к пище;
- обязательную фразу:
  **Не является лекарственным средством.**
- форму выпуска;
- количество / массу / объём;
- краткое официальное назначение;
- основные действующие компоненты;
- краткий способ применения.

Назначение формулировать только как:

- рекомендуется в качестве...
- рекомендуется для...
- является источником...

---

## Особенности формирования карточки

Состав переносится полностью.

Если есть содержание активных веществ (мг, мкг, %, суточная норма) — сохранить.

Раздел "Взаимодействие" выводить только если он присутствует.

Особые указания выводить только при наличии.

## Запрещено

Использовать слова, создающие впечатление лечебного действия.
